这是原创教学网站，非 POT 官方译本。所有示例以 POT 0.9.6.post1 验证。网站示例图为合成数据，不作实际任务性能主张。浏览器 JavaScript 求解器与 POT Python 示例独立实现。

## 内容审计与修正

本地 Claude Code 参与初稿写作，独立的 Claude Code 只读复审同时完成，确认了 FGW、绝对传输质量、分位数、切片目标等关键问题，并补充了单位、熵最大化和研究指标问题；主作者逐项修正后复核。主作者依据数学定义、POT 官方文档、已安装版本与实际数值结果审校，未把初稿直接发布。发现并修正的实质问题包括：

|问题|最终处理|
|把正则计划成本开根后称为精确 W₂|区分 EMD 最优成本、正则计划线性成本、完整正则目标与去偏散度|
|离散分位数使用线性插值|改为阶梯广义逆；合并累计质量断点，保留精确区间权重|
|FGW 的 α 方向反写|统一为 (1−α)特征 + α结构，并与真正 POT FGW 返回目标交叉核验|
|GW 梯度缺因子、可行解被误记为 argmin|对称情形梯度补因子 2；算法可行目标明确是全局最小值上界|
|把部分 OT 的 m 当比例|改为绝对质量，并增加总质量为 2 与 3 的接口检查|
|混淆非平衡的计划正则与边缘正则|明确 reg_type='kl' 的计划参考矩阵 abᵀ、reg_m 的边缘惩罚与可增减质量|
|要求更多切片方向趋于原空间 W₂|改为高方向数 SW₂ 参考；同一方向下与 POT 切片函数核验|
|把 sinkhorn2 的梯度等同于计划|明确完整最优值的包络梯度；另做线性报告值的有限差分反例|
|重心映射要求一一对应|补充允许多个源点映到同一目标的正确充分条件|
|自由支撑、Brenier 定理缺少条件|区分具体 POT 接口与一般模型；写明绝对连续等条件|

## 数值与覆盖边界

浏览器 Sinkhorn 使用 log 域、最多 4000 次迭代、收敛阈值 10⁻⁹。在 952 个滑块组合中，21 个较难组合达到迭代上限；最大边缘误差约 6.15×10⁻⁵。这些情况会醒目标注“尚未满足误差阈值”，不会宣称已收敛；测试验证状态报告与残差一致。展示未收敛状态也是数值诊断教学的一部分。

结构实验仅枚举四节点置换（24 种），是等权双射限制下的结构问题，不是一般 GW 求解器。GW/FGW 完整例子由 POT Python 实现。非平衡、部分传输、去偏和梯度等扩展也通过 Python 示例展示，未声称浏览器已实现所有 POT 功能。

示例基线：Windows / Python 3.13 / POT 0.9.6.post1；GitHub Actions 另在 Ubuntu / Python 3.13 执行检查。依赖版本与锁文件随代码保存。测验不是掌握全部理论的证明；正文仍欢迎读者报告可复现的错误。
