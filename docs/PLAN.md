# 看见最优传输：课程规划

## 面向谁，学完能做什么

面向会基础 Python 与矩阵运算的中文学习者。以原创直觉、准确公式、可复现实验建立从入门到研究实践的路径。高级主题提供明确假设、诊断与论文入口，不以篇幅代替真正的研究训练。

## 课程结构

|阶段|章节|验收能力|
|---|---|---|
|直觉入门|01 为什么需要 OT；02 分布、支撑与成本|区分位置、权重、成本；检查质量守恒|
|数学基础|03 Monge/Kantorovich；04 Wasserstein；05 对偶|手算 2×2 LP，解释开根，对照原始/对偶目标|
|核心算法|06 熵正则与 Sinkhorn；07 去偏散度|推导迭代，检查残差，区分三个目标值|
|进阶应用|08 重心；09 非平衡与部分 OT；10 GW/FGW；11 切片；12 应用|按数据几何与质量选择模型并解释限制|
|研究实践|13 可微与数值诊断；14 研究复现|有限差分验证梯度，设计消融与毕业项目|
|研究专题|15 近期顶会应用；16 空间转录组；17 空间基因与专利线索|将论文任务翻译成质量/成本/约束，并区分公开证据、教学模型和当前未知|

每章：学习目标 → 原创中文讲解 → 公式及符号 → 交互实验 → 独立 Python 代码 → 常见误区 → 自测与答案 → 推导练习 → 官方/论文入口。

## 交互与图示设计

1. 两源三目标质量搬运：调质量与成本，显示精确一维耦合、矩阵、成本和边缘误差。
2. 对数域 Sinkhorn：调 ε，观察稠密程度、计划熵、完整正则目标、收敛状态。
3. 概率混合 vs 位移插值：用同一对分布展示“改权重”和“移动位置”的差别。
4. 切片：旋转投影方向、改变方向数，对比单向距离与多向估计。
5. 结构：旋转与形变四节点图，枚举置换，明确它与完整 GW 的差别。
6. 基因空间分布：固定表达直方图，比较聚集与棋盘排列；切换距离幂次、坐标尺度，观察 W₁/W₂²。

图示包括 17 张章首速写、24 张原理论章节的段落图，以及 23 张新专题图，共 64 张原创 SVG。新图使用矩阵、质量柱、点云、分位数、检验与应用流程表达具体概念。图示同步导出到 Markdown/Notebook 下载合集。每章挂载适用的实验；非平衡/部分 OT 等扩展通过同章 Python 示例验证。

## 技术与交付

- 静态 HTML/CSS/ES modules；KaTeX 随站点打包，不依赖运行时 CDN。
- 搜索、阶段筛选、章节链接、测验反馈、仅本机的阅读进度、打印样式。
- 17 份脚本、17 份 Notebook、带图完整 Markdown、合集 ZIP。
- GitHub Pages 子路径部署；GitHub Actions 验证数学测试、运行全部示例后发布。
- 依赖锁文件；Python 基线 POT 0.9.6.post1。前端求解器为教学用途，真实实验用 POT。

## 审计门槛

1. 内容：变量定义、质量/单位、W_p 根号、熵符号、函数返回值、非凸边界。
2. 数值：手算与精确解、边缘残差、所有参数端点、有限差分、独立示例执行。
3. 界面：桌面与手机、所有章节导航与公式、实验控件、下载、测验与进度。
4. 发布：仅新项目文件入库；不包含 .work、虚拟环境、凭据；实际 Actions 和公开 URL 成功后才报告上线。
